Your phone's apps on your Linux desktop

YASDE turns one window on your Linux PC into a desktop. The apps of your Android phone open as windows inside it, and you use them with mouse and keyboard.

What it does

With YASDE you can

YASDE is an independent project. It is designed for Android 14 or later phones of any make, using only standard Android.

  • Keep a desktopA wallpaper, app icons and widgets, and a taskbar with a launcher. Open the phone's apps in separate windows, several at the same time.
  • Type and pasteType with the PC keyboard and copy and paste text in both directions.
  • Hear the appsThe phone's app sound plays through the PC speakers.
  • Widgets and notificationsDark glass widgets on the desktop, which you can resize from a corner: weather, calendar, battery, storage, quick notes, recent calls, network and now playing. Read the phone's notifications on the PC.
  • Files and APKsSend files to the phone, download files from it and install an APK.
  • Screenshots and recordingsTake screenshots and record an app's screen.
  • The real screenOpen a window that mirrors the phone's real screen.

How it works

A desktop in one window

A single YASDE window on the PC is the desktop. The apps keep running on the phone.

1.One window

A single YASDE window on the PC is the desktop.

- - →

2.Apps stay on the phone

They keep running there, with their data and accounts. YASDE sends their picture and sound to the PC.

- - →

3.Mouse and keyboard

Your clicks and keystrokes go back to the phone.

- - →

4.Nothing to install

No app on the phone, no root access. What YASDE changes while it runs is put back when it closes.

2.Make it executable

In your file manager open the file's properties and allow running it as a program, or type in a terminal:

chmod +x YASDE-{{VERSION}}-x86_64.AppImage

3.Start it

Double-click the file, or run it from a terminal. A single YASDE window opens.

At the first start it shows Connect your phone; the User Manual goes on from there. YASDE adds no menu entry, no launcher and no icon: the file runs from where you put it.

To check the downloads, put SHA256SUMS next to them and run sha256sum -c --ignore-missing SHA256SUMS. The licence is on the licence page.

What it needs

What you need

YASDE is a single file for Linux PCs with an x86-64 processor. It is about 20 MB and already contains GTK 4 and the video libraries it needs.

What the PC and the phone need
NeededDetails
Operating systemLinux, 64-bit x86, with glibc 2.38 or newer, and a graphical session (X11 or Wayland).
GraphicsA Vulkan driver for your graphics card. Without libvulkan the program does not start. Video decoding uses VA-API when the card offers it, so libva and libva-drm must be present.
SoundPipeWire: its library libpipewire-0.3 must be present (the program does not start without it) and the PipeWire service must be running to hear sound.
System librarieslibdrm, fontconfig, and the usual X11, XCB and Wayland client libraries; any recent desktop has them.
Starting the AppImageThe AppImage carries its own FUSE 3 library, but the system must provide the program fusermount3 or fusermount (package fuse3 or fuse) with FUSE enabled.
PhoneAndroid 14 or later, with Wireless debugging turned on (the User Manual explains how).
NetworkThe PC and the phone on the same Wi-Fi network.

The list comes from what the package asks of the system. YASDE has not been tried on every Linux distribution, so a system older than the one described may need more.

What has been tried

Status and limits

What the manuals say has and has not been tried.

  • Tried on one phone so far. YASDE is designed for Android 14 or later phones of any make, using only standard Android, but it has been tried on one phone so far.
  • Not tried on every Linux distribution. A system older than the one described may need more.
  • Two cases not tried live. Two cases are described in the User Manual as not tried live: the phone no longer recognizing the PC, so that it must be paired again, and the phone being kept awake again after the PC comes back from a lost connection.
