Un desktop dentro il telefono

Nessun cavo, nessuna installazione: basta il Debug wireless.

1. Finestra principale ridimensionabile
2. Barra con launcher e notifiche
3. Widget della shell
4. Opzione schermo intero
5. Blocco come in DeX
